# Interactive Calculator and Unit Converter

## Project Overview
This project is developed using Python. It provides basic arithmetic operations and unit conversions through a menu-driven command-line interface.

## Features
- Addition, subtraction, multiplication and division.
- Kilometers to miles conversion.
- Celsius to Fahrenheit conversion.
- Kilograms to pounds conversion.
- Input validation using try-except.
- Handles division by zero.
- Menu repeats until the user selects Quit.

## Technologies Used
- Python
- Python IDLE

## Conversion Formulas
- Miles = Kilometers × 0.621371
- Fahrenheit = Celsius × 9/5 + 32
- Pounds = Kilograms × 2.20462
